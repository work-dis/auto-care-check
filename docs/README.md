# AutoPulse — официальная техническая документация

- **Статус:** соответствует текущей реализации P0–P7.
- **Версия:** 1.1.
- **Дата актуализации:** 2026-07-25.

Эта папка является основной точкой входа для разработчиков, ревьюеров и
операторов AutoPulse. Исходные продуктовые требования остаются в
`autopulse_car_service_specs/`, а документы ниже описывают фактическую кодовую
базу, реализованную архитектуру и правила её эксплуатации.

## Источники истины

При конфликте документов действует следующий приоритет:

1. требования безопасности и защита пользовательских данных;
2. миграции Prisma и фактическая схема данных;
3. реализованные API-контракты и автоматические тесты;
4. документы этой папки;
5. исторические спецификации в `autopulse_car_service_specs/`;
6. комментарии в коде.

Любое изменение поведения должно сопровождаться обновлением соответствующего
документа, тестов и записи в `docs/decisions/`, если меняется архитектурное
решение.

## Definition of Done проекта

Релиз считается готовым только когда:

- `npm run lint`, `npm run typecheck`, `npm test` и `npm run build` завершаются
  успешно в чистом окружении;
- миграции применяются к пустой и к предыдущей production-схеме;
- все изменяющие данные API проверяют аутентификацию, владение ресурсом и входную
  схему;
- cron можно вызвать только через `CRON_SECRET`, и его запуск подтверждён
  интеграционным тестом;
- документация и `.env.example` соответствуют фактической реализации;
- для критических изменений подготовлены rollback и наблюдаемые сигналы.

Исторический пакет в `autopulse_car_service_specs/` объясняет исходный замысел,
но не является справочником фактически доступных маршрутов или полей БД.
